# Local fonts

Latin variable WOFF2 files recovered from this project's existing Next.js font cache.
Self-hosting removes Google Fonts network access as a build requirement.

- Hanken Grotesk (100–900): https://github.com/google/fonts/tree/main/ofl/hankengrotesk
- Syne (400–800): https://github.com/google/fonts/tree/main/ofl/syne

Both fonts are distributed under the SIL Open Font License 1.1.
